# Aurelle theme design
Approved direction: build a standalone HTML/CSS/JavaScript beauty storefront inspired by the supplied Wix Beauty Store (Bold) reference. Use burgundy, warm cream, pink, large lowercase display type, photography, and spacious product grids. Preserve Mellow storefront content capacity across home, collections, product, cart, wishlist, checkout, customer accounts, password recovery, order tracking, payment handoffs, and customer-facing store information pages.

Destination: aurelle in /Users/Wills/Desktop/Ogaranya Projects/mello-theme ideas. Shared CSS and plain JavaScript, no build dependencies. Local demo state must be identified in documentation and forms involving identity/payment must not imply real server transactions. HTML pages contain their main content; shared navigation and dynamic product data use JS. Local images are bundled. Backend data contracts are documented separately from static demonstrations. Mobile, keyboard, reduced motion, missing/empty/error states and price/stock/options are part of the design.

Scope correction: merchant administration and customization UI are excluded. Account pages are customer account pages.
