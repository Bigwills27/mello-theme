# Buttercup verification inventory

- All 40 customer HTML pages: HTTP load, image availability and viewport fit at 1440, 768 and 375px.
- Shared shell: menu/dropdowns/mobile drawer/search, cart preview, wishlist counters, footer and absence of merchant controls.
- Homepage: reference composition, banners, category tabs, all Mellow collection types, absent optional sections, empty/error/retry states.
- Product: required single/multiple options, disabled choices, percentage/fixed/packaging prices, variant media/stock, quantity boundaries, cart/wishlist, thumbnails/lightbox/Escape and paginated reviews.
- Listing: context/search, attributes, filter chips, stock/rating/sale and price filters, sorting, pagination, page size, grid/list and mobile filter toggle.
- Cart/checkout: coupon states, option preservation, clear confirmation/cancel, delivery/pickup/digital fields, configured fee exemption, no customer fee waiver control, generic external-provider handoff.
- Payments: failure retains bag, checkout shows feedback, success clears bag, provider identity retained, confirmation includes products.
- Customer: registration mismatch and profile preview, no password storage, profile updates/logout, recovery/expired tokens, paginated sample orders, eligible/ineligible downloads, missing order/reference.
- Compatibility: separate Buttercup browser state and RTL viewport fit. Static links/assets and JS syntax are checked separately.

- Account visual review: all eight account routes at 1440px and 375px; no old auth-wrap/account-layout/sidebar/stats/table structures, no overflow, no broken images, and fresh screenshots.
